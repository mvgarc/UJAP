# Repositorio Académico – Universidad José Antonio Páez (UJAP)

Este repositorio contiene **ejercicios, proyectos, ejemplos prácticos y prototipos** desarrollados **íntegramente por mí** como parte de las asignaturas que imparto en la **Universidad José Antonio Páez (UJAP)**.

Todo el contenido ha sido **implementado y probado previamente** con el objetivo de:
- validar la complejidad real de los ejercicios,
- asegurar que los proyectos sean alcanzables por los estudiantes,
- anticipar dificultades técnicas y conceptuales,
- y servir como referencia pedagógica sólida.

---

## Objetivos del repositorio

Este repositorio funciona como:

- 📌 **Repositorio de apoyo académico**
- 🧠 **Material práctico para el aprendizaje de programación, IA y sistemas**
- 🧪 **Base para proyectos finales y experimentación**
- 📖 **Referencia reutilizable para distintas cohortes de estudiantes**
- 🧩 **Banco de ejercicios probados antes de ser asignados en clase**

---

## Asignaturas relacionadas

El material aquí incluido ha sido utilizado o adaptado para materias como:

- Computación Emergente y Tecnologías Disruptivas  
- Inteligencia Artificial  
- Algoritmos Genéticos y Programación Evolutiva  
- Redes Neuronales y Aprendizaje Profundo  
- Simulación y Modelado  
- Lógica Difusa  
- Programación Web y Backend  
- Metodología de la Investigación / Tesis
